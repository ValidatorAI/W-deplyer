# basic understanding of W
Consider W as an organization, each hermes profile is a organizational department, some departments are functional departments like consider a task delegator profile or knowledge profile, some department are divisional department like coder profile
kanban is used as task management system for asynchronouse delegation of tasks by profile
message sends to the delegator profile & delegator decides if it is emergent send it to the specific profile or not emergent put it in the kanban
